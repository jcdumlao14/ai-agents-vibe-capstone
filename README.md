# ai-agents-vibe-capstone

Enterprise-grade AI Agents capstone project focused on customer churn prediction, retention recommendation, and business workflow automation.

## Overview

This repository captures the design, architecture, and implementation plan for a multi-agent BusinessPilot AI solution targeting the Kaggle Agents for Business track.

The project includes:
- AI agent orchestration for customer churn prediction and retention planning
- Clean architecture with separated data, model, agent, and service layers
- Google ADK and MCP integration design
- Cloud deployment guidance for enterprise-ready operation

## Repository Structure

- `docs/` - architecture, roadmap, and design documentation
- `src/` - source code for agents, data pipelines, models, and services
- `tests/` - unit and integration tests
- `deployment/` - deployment and cloud infrastructure guidance
- `.github/` - GitHub issue templates and workflow placeholders

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/jcdumlao14/ai-agents-vibe-capstone.git
   cd ai-agents-vibe-capstone
   ```
2. Review architecture and roadmap documentation in `docs/`
3. Implement or extend the sample components under `src/`
4. Run tests:
   ```bash
   pytest
   ```
