# Contributing to ai-agents-vibe-capstone

Thank you for contributing! This document explains how to contribute, submit issues, and propose changes.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your work.
3. Open a pull request describing your changes.

## Code Style

- Use readable, well-documented code.
- Follow a consistent Python style (PEP 8 recommended).
- Add or update tests for new functionality.

## Development Workflow

- Use `git checkout -b feature/<name>` for new features.
- Keep commits small and focused.
- Rebase or merge upstream `main` before finalizing your pull request.

## Issues and Enhancements

- Open issues for bugs, enhancements, and design proposals.
- Provide clear descriptions, expected behavior, and reproduction steps.

## Pull Requests

- Ensure all tests pass.
- Include documentation updates if necessary.
- Describe the rationale and any implementation details.
