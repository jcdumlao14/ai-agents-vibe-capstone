# Environment Variables

Use `.env` for local environment variables. The project loads environment variables through Pydantic settings.

Required variables:
- `OPENAI_API_KEY`
- `PROJECT_ID`
- `GOOGLE_APPLICATION_CREDENTIALS`
- `APP_NAME` (optional)
- `ENVIRONMENT` (optional)
- `DEBUG` (optional)
- `LOG_LEVEL` (optional)
- `LOG_FORMAT` (optional)
